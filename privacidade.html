Privacidade e estatísticas

O portal Astraryx Idle está hospedado no GitHub Pages. O GitHub pode processar dados técnicos de acesso necessários à entrega das páginas, conforme suas próprias políticas.

Google Analytics 4 (opcional)

Quando uma medição GA4 estiver configurada, o site exibirá uma escolha de consentimento. A biblioteca do Google Analytics não é carregada antes de você permitir estatísticas. Sem um ID GA4 configurado, não ocorre coleta por essa integração.

Se você autorizar, poderemos medir visitas e interações, inclusive cliques em links de download de APK, versão do APK e tamanho aproximado do arquivo. Não enviamos ao GA4 nomes, e-mails, conteúdo de mensagens ou dados do jogo.

O Google pode processar dados técnicos e utilizar cookies de medição quando autorizados. Consulte a Política de Privacidade do Google.

Alterar ou retirar o consentimento

Sua escolha é salva no armazenamento local do navegador. Você pode alterá-la a qualquer momento nesta página. Recusar ou revogar impede novos eventos do site; dados já processados seguem as políticas aplicáveis do Google.

Dados do download e comunidade

O APK é distribuído pelo GitHub Releases, serviço externo. Discussões e relatos de bugs usam o GitHub e podem exigir uma conta. Confira as políticas do GitHub antes de publicar informações.
